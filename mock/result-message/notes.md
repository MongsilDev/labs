# 대회 결과 메시지 시안 메모

`node mock/result-message/render.mjs`로 PNG를 모두 다시 그립니다. 레포에 next/og 의존성이 설치돼 있지 않아 `roundImage`와 같은 색, 글꼴, 크기를 HTML로 옮겨 Playwright로 캡처했습니다.

## 공통 조건

- 가짜 대회 "시험 대회", 8팀, 4라운드 포인트제입니다. 라운드마다 운영자가 게임 결과 CSV를 올리고 2분 뒤 봇이 결과를 올린다고 놓았습니다.
- 데스크톱 캡처는 4라운드가 끝난 상태, 휴대폰 캡처는 2라운드가 끝난 상태입니다. `A-select.png`는 4라운드가 끝난 상태라 select 항목이 5개입니다.
- 메시지 수는 봇 메시지만 셉니다. 순위 행 수는 화면 안에 행 전체가 보이는 것만 셉니다.
- 짐작한 크기: 데스크톱 Container 최대 폭 600px, 이미지 1장은 Container 폭에 맞춤. 휴대폰 이미지 폭은 약 290px(`round-og.tsx` 주석의 약 300px와 비슷). MediaGallery에 2장을 넣으면 두 장이 가로로 나란히 놓이고 칸마다 잘려 보인다고 놓았습니다. 실제 디스코드에서 크기가 다를 수 있습니다.
- 봇 코드(`commands/tournament.py`)는 이 레포에 없어, 아래 함수 변경은 함수 이름만 보고 적은 것입니다.

## A안, 메시지 하나

- 4라운드가 끝났을 때 남는 봇 메시지: 1개
- 한 화면: 데스크톱 메시지 1개, 순위 행 8개 / 휴대폰 메시지 1개, 순위 행 8개
- 바뀌는 함수
  - `notice_view`: 제목, 누적 순위 이미지, 다음 라운드 줄, select, 링크 버튼을 담는 하나의 view가 됩니다.
  - `round_view`: 없앱니다. select로 고른 라운드의 게임 순위 이미지를 ephemeral로 보내는 응답을 새로 만들어야 하고, 라운드 하나의 게임 순위 이미지는 지금 `roundImage`가 그리지 않으니 웹 쪽에 새 이미지 경로가 필요합니다.
  - `post_round`: 이전 메시지를 지우고 새 메시지를 올린 뒤 메시지 ID를 저장합니다.
  - `tick`: 개요 메시지 수정이 없어집니다.
- 재시작 뒤: select를 `DynamicItem`으로 등록하고 custom_id에 대회 코드와 조를 넣으면 동작합니다. 링크 버튼은 봇과 상관없이 동작합니다.
- 지시문과 다른 점: 디스코드에서 Action Row 하나에는 select 하나 또는 버튼 최대 5개만 넣을 수 있어, select와 링크 버튼을 Action Row 두 개로 나눴습니다.
- 제목 Text Display의 대회 이름과 진행 상황이 바로 아래 이미지 머리글과 겹칩니다.

## B안, 지금 구성 정리

- 4라운드가 끝났을 때 남는 봇 메시지: 5개(개요 1, 라운드 4)
- 한 화면: 데스크톱 메시지 2개(위 메시지는 이미지 아래 끝만 보임), 순위 행 8개 / 휴대폰 메시지 2개, 순위 행 13개(위 메시지 5행 + 아래 메시지 8행)
- 바뀌는 함수
  - `notice_view`: 다음 라운드 줄과 금지 실험체 줄을 뺍니다.
  - `round_view`: 이미지와 다음 라운드 줄, 금지 실험체 줄만 둡니다. 링크 버튼을 뺍니다.
  - `post_round`: 지난 라운드 메시지에서 다음 라운드 줄을 빼는 수정은 지금처럼 둡니다.
  - `tick`: 개요 메시지에서 진행 상황 줄만 고칩니다.
- 재시작 뒤: 링크 버튼만 있어 그대로 동작합니다.
- 2라운드부터 개요 메시지가 화면 밖으로 밀려, 순위표 버튼과 CSV 안내 줄은 채널을 위로 올려야 보입니다.
- 지시문의 "다음 라운드 줄"에 금지 실험체 줄도 들어간다고 보고, 라운드 메시지에 두 줄을 같이 뒀습니다.

## C안, 라운드 메시지에 두 장

- 4라운드가 끝났을 때 남는 봇 메시지: 4개
- 한 화면: 데스크톱 메시지 2개, 순위 행 26개(위 메시지 2장의 일부 + 아래 메시지 16행) / 휴대폰 메시지 2개, 순위 행 32개
- 바뀌는 함수
  - `notice_view`: 없앱니다.
  - `round_view`: 제목 Text Display와 이미지 2장, 다음 라운드 줄, 링크 버튼을 둡니다.
  - `post_round`: 라운드 하나의 게임 순위 이미지도 같이 올립니다. A안처럼 새 이미지 경로가 필요합니다.
  - `tick`: 개요 메시지 수정이 없어집니다.
- 재시작 뒤: 링크 버튼만 있어 그대로 동작합니다.
- 두 장이 나란히 놓여 한 장 폭이 데스크톱 약 280px, 휴대폰 약 140px입니다. 행은 화면 안에 들어오지만 휴대폰에서는 글자가 5px 안팎이라 읽을 수 없습니다. 이미지를 누르면 크게 볼 수 있습니다.
- 개요 메시지가 없어 "이 채널에 올린 게임 결과 CSV는 순위에 반영됩니다." 안내가 빠집니다.

## 점수 표기

2라운드 누적 순위입니다. 표의 숫자는 720 폭 기준으로 잰 정수 자리 오른쪽 끝의 위치입니다.

| 안 | 킬 점수 열 | 총점 열 | 정수 자리 |
| --- | --- | --- | --- |
| F1 | 495 | 604 | 열마다 한 위치. 순위 점수 열도 438 한 위치 |
| F2 | 496.3, 496.5 | 604.9, 605.4 | 0.5px 안에서 맞음 |
| F3 | 496.5, 520 | 605.4, 636 | 정수 값만 23~31px 오른쪽으로 밀림 |

- F1은 열이 하나 늘어 팀 이름 칸이 720 기준 352px에서 262px로 줄어듭니다. 긴 팀 이름은 더 일찍 말줄임됩니다.
- F1은 Pretendard의 tabular-nums를 씁니다. 같은 크기에서 "1111"과 "0000"의 폭이 같은 것을 확인했습니다.
- 300px 사본에서 글자 크기는 팀 이름 약 12px, 킬 점수 약 11px입니다.
